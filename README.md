# Number Guessing Game

A simple number guessing game built with Python.

## Features

* Three difficulty levels: Easy, Medium, and Hard
* Random number generation
* Hints to help the player guess the number
* Counts the number of attempts
* Handles invalid difficulty selections

## Difficulty Levels

* Easy: Guess a number between 1 and 50
* Medium: Guess a number between 1 and 100
* Hard: Guess a number between 1 and 500

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python number_guessing_game.py
```

## Technologies

* Python
* Random module
